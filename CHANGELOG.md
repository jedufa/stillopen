# Changelog

## 1.0.0-oss.1 — 2026-10-12

Initial Android-focused MIT source prerelease, experimental and unmaintained; independent forks welcome. Current Flutter implementation, tests and synthetic fixtures are included. Private infrastructure, historical evidence and uncertain branding images are omitted. Simple code/vector branding placeholders and an official checksum-verified Gradle wrapper provide a standalone debug build path.

Analyzer, 183 unit/widget tests, Android debug build and synthetic native lifecycle/recurrence/backup/restart checks passed. Physical-device delivery, camera/provider/OEM sharing and iOS remain unverified.
